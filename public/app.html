关于 Acaily

Acaily 是飞书 AI 助手，核心理念是 模型选择权下放到每位成员：你用自己的 API Key 接任意大模型，组织只做网关路由与安全合规，看不到你的密钥明文。

个人模型网关 信封加密 租户隔离 飞书原生 审计留痕

怎么用

  1. 在「Provider」填写 Provider / Base URL / Model / API Key 并保存。
  2. 在飞书任意会话里 @Acaily 并提问，或在本页「对话」里直接聊。
  3. 管理员可在「管理后台」统一查看成员配置与审计日志。

绑定飞书应用

把这个智能体绑定到一个飞书自建应用；绑定后成员 @ 该应用即可与该智能体对话。

步骤：① 在 飞书开放平台 → 创建企业自建应用，添加「机器人」能力并发布版本；② 把下面要的两个值复制进来。

在飞书组织内自动创建一个自建应用并绑定。需要主应用具备 application:application:create 权限；若主应用未通过企业开发者认证，此处通常会失败，请改用「手动绑定」。
